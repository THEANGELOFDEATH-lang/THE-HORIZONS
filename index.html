The Arduino Uno R3 is a microcontroller development board. It reads inputs, runs instructions written in a program and controls connected electronic devices.

WHAT DOES IT DO?

  • Reads signals from sensors and input devices.
  • Controls outputs using digital and PWM pins.
  • Can send movement commands to a motor driver.
  • Can update an LCD with information from the program.

IMPORTANT SPECIFICATIONS

  • Microcontroller: ATmega328P.
  • Operating logic voltage: 5 V.
  • Digital input/output pins: 14, including 6 PWM-capable pins.
  • Analog inputs: 6.
  • Typical clock speed: 16 MHz.

HOW IT FITS INTO RC-01

The Arduino can process distance measurements and decide which motor commands to send to the L298N. The exact behaviour depends on the program and wiring.

Remember: Never assume a pin is available without checking the complete wiring and code.

The L298N is a dual H-bridge motor driver IC commonly found on modules used in small robotics projects. It allows low-power control signals to control the direction of suitable external motor loads.

WHAT DOES IT DO?

  • Provides control for two DC motor channels.
  • Changes motor direction through input combinations.
  • Can support speed control using suitable PWM signals.
  • Separates motor power requirements from the Arduino's signal pins.

COMMON MODULE CONNECTIONS

  • IN1–IN4: motor direction inputs.
  • ENA and ENB: channel enable or speed control, depending on module configuration.
  • OUT1–OUT4: motor output terminals.
  • Motor power and logic power must follow the specific module's documentation.

HOW IT FITS INTO RC-01

The Arduino sends control signals to the driver. The driver then controls the connected motors. Forward, reverse and turning behaviour depends on the motor wiring and program.

Important: The L298N can become hot and has a noticeable voltage drop. Check motor current, supply voltage, cooling and module limits before use.

An ultrasonic distance sensor sends a high-frequency sound pulse and measures how long it takes for the echo to return from a nearby object.

HOW DISTANCE IS ESTIMATED

Sound travels to the object and back, so the measured time represents a round trip. A simplified calculation is:

Distance = Echo time × Speed of sound ÷ 2

COMMON HC-SR04 CONNECTIONS

  • VCC: supply voltage, typically 5 V for the HC-SR04.
  • GND: ground.
  • TRIG: trigger pulse from the controller.
  • ECHO: pulse indicating echo travel time.

HOW IT FITS INTO RC-01

  • Measures the approximate distance to objects in front of the sensor.
  • Can trigger a stop or turning decision in suitable code.
  • Can provide distance readings for an LCD display.
Remember: Readings can be affected by object shape, surface, angle and surrounding conditions. Check the sensor's voltage requirements before connecting it.

A 16×2 character LCD displays up to 16 characters on each of two rows. It can make a robot easier to monitor without needing a computer screen.

WHAT CAN IT DISPLAY?

  • Robot status such as READY, MOVING or STOPPED.
  • Distance readings from a compatible sensor.
  • Selected operating modes.
  • Simple messages that help with testing and debugging.

COMMON CONNECTION OPTIONS

  • Parallel interface: uses several data and control pins.
  • I²C adapter: uses SDA and SCL for communication, with the correct library and address.
  • Contrast and backlight settings depend on the display module.

HOW IT FITS INTO RC-01

The Arduino can refresh the LCD with information such as the measured distance or the robot's current programmed state.

Remember: A display with an I²C adapter and a standard parallel LCD need different wiring and code. Check which type your project uses.

DC gear motors combine a DC motor with a gearbox. The gearbox reduces rotational speed and increases the available output torque compared with the motor operating without that reduction.

WHY USE THEM?

  • Provide wheel rotation for movement.
  • Gear reduction can help a small car move under load.
  • Separate left and right motor control can support turning.

IMPORTANT THINGS TO CHECK

  • Rated motor voltage.
  • Operating and stall current.
  • Gear ratio, output speed and torque.
  • Wheel size, traction and total robot weight.

HOW IT FITS INTO RC-01

The motor driver controls the connected motors. The resulting movement depends on the chassis, motor placement, wiring and control program.

Safety: A motor can draw much more current when stalled than when spinning freely. Choose the driver and power source accordingly.

A robot's power system must supply the voltage and current required by its controller, driver, motors and display. The correct setup depends on the actual components used in the build.

WHAT SHOULD BE CONSIDERED?

  • Use a suitable supply for the motors and motor driver.
  • Supply the Arduino using a supported input method.
  • Check the current needs of every connected component.
  • Use secure connections and suitable wiring.
  • Follow the required common-ground arrangement for control signals.

WHY DOES POWER MATTER?

An undersized or unstable supply may cause resets, weak motors, display glitches or unreliable sensor readings.

Important: Never connect a battery directly to a component without checking its voltage requirements and polarity.
